Agent Coders Clinic

Participant Guide

What is the Agent Coders Clinic?

The Agent Coders Clinic is a hands-on workshop where you’ll learn to use AI coding agents — tools that can read your files, run commands, edit code, and work through multi-step tasks on your behalf. Whether this is your first time using an AI coding tool or you’ve been experimenting on your own, this clinic will give you a practical workflow you can take back to your daily work.

What you’ll learn

By the end of this clinic, you will:

  • Understand what an agentic coding harness is and how it differs from chatbots or autocomplete
  • Get Claude Code or Antigravity running on the JupyterHub — no AI account or subscription of your own needed
  • Practice a clear–handoff–notes workflow that keeps your work organized across sessions
  • Use an agent to plan and edit a real Quarto book, with a plan and handoff notes between sessions
  • Teach the agent your workflow (task → branch → pull request) and write skills for tasks you repeat

The environment

Everything runs on a sandboxed JupyterHub. You have a terminal, a file browser, and your choice of coding tool. Nothing connects to private or confidential systems — this is a safe space for learning and experimenting.

Agenda

Time Topic
First half Setup, intro to agentic coding, core workflow (clear / handoff / notes)
Second half Activity: edit a Quarto book with an agent; agent skills

Ready?

Start with Setup: log in to the hub, run the setup script for Claude Code or Antigravity, and choose how much of your GitHub the agent can reach.
